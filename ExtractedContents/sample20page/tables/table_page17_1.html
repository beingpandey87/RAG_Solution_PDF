border='1'> Code Status Description 200 OK The request was successful. 201 Created A new resource was created. 301 Moved Permanently The resource has been moved to a new URL. 302 Found The resource is temporarily at a different URL. 400 Bad Request The request was malformed or invalid. 401 Unauthorized Authentication is required. 403 Forbidden The server refuses to authorize the request. 404 Not Found The requested resource does not exist. 500 Internal Server Error The server encountered an unexpected condition. 502 Bad Gateway The server received an invalid response from upstream. 503 Service Unavailable The server is temporarily unable to handle the request.
